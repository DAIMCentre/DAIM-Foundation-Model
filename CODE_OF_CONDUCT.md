# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, welcome newcomers, and keep
criticism focused on ideas and code rather than people. Harassment of any kind
is not tolerated.

To report unacceptable behaviour, contact the maintainers through the
[DAIMCentre GitHub organisation](https://github.com/DAIMCentre). Reports are
handled in confidence.
